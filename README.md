# Web-development-project
Overview

My Art Nook is a multi-page website I developed as a school project to provide children with accessible, step-by-step drawing tutorials and information about online art classes. The website was designed to make learning art approachable through illustrated instructions, organized navigation, and a warm, consistent visual style.

Technologies Used
HTML5: Structured the website's pages, navigation, tutorial content, images, and sign-up form.
CSS3: Styled the page layouts, colours, typography, navigation bar, tutorial sections, image galleries, and footer.
Font Awesome: Used icons for social media links.
External resources: Linked to an externally hosted Font Awesome stylesheet and included a bibliography page to acknowledge reference materials.
Key Features
Homepage and tutorial gallery: Displays drawing projects, including a panda drawing and a tissue paper portrait, with links to their step-by-step tutorials.
Step-by-step drawing tutorials: Presents illustrated drawing instructions alongside written explanations.
Navigation and page organization: Provides navigation between the homepage, junior and senior art class pages, and other website content.
Online class sign-up form: Includes fields for a student's name, parent or guardian contact information, preferred class, available days, and time slots.
Consistent visual design: Uses coordinated colours, styled content sections, image layouts, and a shared footer across multiple pages.
Interactive visual elements: Includes hover effects, a scrolling navigation bar, a typewriter-style heading animation, and a button that scrolls to the author information.
Bibliography: Includes a dedicated page documenting selected external resources used in the project.
Project Structure

The website consists of multiple HTML pages and a shared CSS stylesheet. The pages include:

HomePage.html — Homepage and tutorial gallery
artOne.html — Tissue paper portrait tutorial
artTwo.html — Panda drawing tutorial
juniorArt.html — Junior art class information
seniorArt.html — Senior art class information
Form.html — Online class sign-up form
bibliography.html — Reference materials
style.css — Shared styling for the website
Photos/ — Images and other visual assets used throughout the website

The project also includes a thank-you page referenced by the sign-up form.

How to Run
Download or clone this repository.
Keep the HTML files, style.css, and the Photos/ directory in their expected locations.
Open HomePage.html in a web browser.
Navigate through the tutorial pages and other website sections using the available links and menus.
What I Learned

This project gave me practical experience building a multi-page website, structuring content with HTML, styling layouts with CSS, organizing shared resources, and creating navigation between pages. It also introduced me to designing forms and adding interactive behaviour to a website.

Future Improvements
